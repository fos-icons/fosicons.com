# CLAUDE.md

## Icon design

Before drawing, redrawing, or reviewing any icon (in Figma or as SVG), read
[`docs/ICON-STYLE.md`](docs/ICON-STYLE.md) and follow it. Run its review
checklist on every icon before calling it done. That file is the source of
truth for icon style and will keep changing; re-read it each session rather
than relying on memory.
